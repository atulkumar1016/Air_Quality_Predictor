# Air_Quality_Predictor
AQI-Shield is a machine-learning powered web application built with Flask. It predicts Air Quality Index values using trained regression models and provides real-time air quality categorization with a clean, responsive interface.


# AQI Shield  

[Live Demo](https://air-quality-predictor-ulev.onrender.com)  

🔍 Overview  
AQI Shield is India’s powerful real-time air-quality intelligence platform. It gives live data, predictions and alerts across major cities.  

🚀 Features  
- Real-time AQI updates (e.g., Delhi, Mumbai, Bangalore, …)  
- AI-powered prediction model with ~99.1% accuracy  
- Hyper-local data: street-level updates every 5 minutes  
- Health alerts via SMS & push notifications  
- Clean UI & dashboard for users  

🛠️ Tech Stack  
- Front-end: (e.g., React, HTML/CSS/JS)  
- Back-end: (e.g., Flask/Django/Node.js)  
- Model: Deep Learning model for prediction  
- Deployment: Render (or platform you used)  
- Data: Live sensor data + past AQI datasets

Flight_prices_prediction
AirVista ✈️ is an intelligent and lightweight Flight Price Prediction system built using a RandomForest Regressor optimized with SelectKBest feature selection, achieving an overall 🎯 83.27% prediction accuracy. The project follows a complete machine-learning workflow — including data cleaning, time/route feature engineering, categorical encoding, and top-feature extraction — to ensure a stable and reliable model. The web interface is developed in Flask, offering a modern, responsive UI where users can select airline, route, departure time, and stops to instantly receive predicted ticket prices. Designed with real Indian flight patterns in mind, AirVista is fast, practical, and fully deployment-ready. 🚀✨

✔️ RandomForest (KBest-optimized) chosen as the best-performing model

✔️ Achieves 83.27% accuracy on test data

✔️ Uses SelectKBest (f_regression) to extract the most impactful features

✔️ Complete preprocessing pipeline (cleaning, encoding, time extraction, duration parsing)

✔️ Instant predictions through a smooth Flask web interface

✔️ Fully structured, lightweight, and easy to deploy on Render/Vercel/Railway

✔️ Designed using real patterns of Indian domestic flight data

Live Demo: https://airvistaflies.onrender.com

About AQI Shield 🌍

AQI Shield ek smart web application hai jo air pollution ko analyze aur predict karta hai. Yeh system PM2.5, PM10, NO2 aur SO2 jaise pollutants ka use karke AQI calculate karta hai.

Is project ka goal hai logon ko real-time awareness dena taaki wo apni health protect kar saken.

Technologies Used:
✔ Python (Flask)
✔ Data Analysis (Pandas)
✔ Visualization (Matplotlib / Seaborn)
✔ Frontend (HTML, CSS)

Built with ❤️ for environment safety.
